# test-gitsensor-target

Collection of EmELand YAML resource files used as test fixtures for the git sensor.

## YAML Style Guide

All YAML files in this repository must conform to the following rules (enforced by `yamllint` in CI):

- 2-space indentation
- Sequences indented consistently
- Maximum line length: 120 characters
- At least 1 space between content and inline comments
- Files must end with a newline

The full configuration is in [`.yamllint.yml`](.yamllint.yml).
